# Edge 企业信息自动采集扩展

当前版本：`0.1.5`

## 安装

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本目录 `edge-extension`。
4. 将“企业信息自动采集助手”固定到浏览器工具栏。

## 使用

1. 启动本地项目并创建企业任务。
2. 在项目页面点击“复制 Edge 扩展配对信息”。
3. 打开扩展，将配对信息中的项目地址、配对码和任务编号填入扩展。
4. 点击“保存并开始”，扩展会将当前企业名称或信用代码填入官网搜索框。
5. 用户手动点击官网“查询/搜索”并完成验证码或安全验证，然后点击扩展中的“我已完成验证，继续”。扩展不通过脚本点击查询按钮，避免触发官网对非人工事件的限制。
6. 同名企业有多个候选时，由用户选择正确企业并进入详情页，再点击继续。
7. 扩展读取企业详情页文字并发送到 `127.0.0.1:8080`，本地项目解析、保存并切换下一家。

采集成功后会自动保存，不需要在扩展中再次确认。基本信息已保存但扩展栏目缺失时，任务会进入“待审核”，扩展继续下一家；后续在项目页面使用“人工补录”完善。

扩展固定使用一个国家企业信用信息公示系统标签页，防止多个标签页重复输入或重复采集；两家企业之间至少间隔 8 秒。扩展会尝试点击所有可见的“全部展开/展开全部”，但不会自动遍历官网独立分页。

## 更新

扩展文件更新后，在 `edge://extensions/` 页面点击“重新加载”。项目重启后配对码会变化，需要从项目页面重新复制配对信息。

## 安全说明

扩展不会读取或上传 Cookie、账号和密码，不会自动点击官网查询按钮，也不会绕过验证码或访问频率限制。出现“IP 请求异常”、403 或 521 时，请点击“停止采集”，不要继续刷新或重试，等待官网解除限制后再继续。
