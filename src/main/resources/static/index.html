企业信息自动采集

导入企业名单或输入企业名称后，系统会打开国家企业信用信息公示系统。用户仅需在浏览器中完成验证码；唯一匹配的企业将自动采集全部公开栏目，多候选企业才需要人工选择。

一、创建企业任务

支持 CSV/XLSX，按企业名称去重。

二、自动采集任务

Edge 扩展自动采集（推荐）

在 Edge 打开 edge://extensions/，启用“开发人员模式”，加载程序目录中的 edge-extension 文件夹。创建任务后复制配对信息，粘贴到扩展即可开始。
扩展自动填写查询内容；用户手动点击官网查询并完成验证码，验证后的选择、采集和切换由扩展继续。扩展不会读取或上传 Cookie、账号和密码。
